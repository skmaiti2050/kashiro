# Hindi and Bengali: tone guide

Short rules for the interface text in `hi.json` and `bn.json`. The wider guide is [TRANSLATING.md](TRANSLATING.md).

- **Write like a helpful person** explaining what to do next, not like a textbook or a form. Conversational,
  not academic.
- **Familiar loanwords are fine, and preferred** where people already use them: save, settings, text,
  review (सेव, सेटिंग्स, टेक्स्ट / সেভ, সেটিংস, টেক্সট).
- **One word per concept**, used the same way everywhere.
- **Technical terms only where they make an explanation clearer.** "Consonant sound" helps in the a/an
  explanation; it doesn't help in a button.

Example (the a/an explanation in Bengali): শব্দের শুরুতে ব্যঞ্জনের মতো আওয়াজ হলে “a”, আর স্বরের মতো আওয়াজ হলে “an” বসে।
